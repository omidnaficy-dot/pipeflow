PipeFlow 🚰
اپ آموزشی Streamlit برای محاسبه‌ی افت اصطکاکی لوله بر اساس معادله‌ی Darcy–Weisbach و ضریب اصطکاک Colebrook.

این اپ صرفاً یک رابط کاربری است؛ تمام محاسبات در هسته‌ی مستقل و آزمایش‌شده‌ی core/pipe.py انجام می‌شود (هیچ فرمولی در UI دوباره پیاده‌سازی نشده است).

ساختار پروژه
text
PipeFlow/
├── app.py            # رابط Streamlit
├── requirements.txt  # وابستگی‌ها
├── README.md         # همین فایل
├── core/
│   └── pipe.py       # هسته محاسباتی (دست‌نخورده و تست‌شده)
└── tests/
    └── run_tests.py  # ۱۰ تمرین مرجع
نصب
bash
cd PipeFlow
python -m venv .venv
source .venv/bin/activate         # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
اجرا
bash
streamlit run app.py
سپس مرورگر روی آدرس پیش‌فرض (معمولاً http://localhost:8501) باز می‌شود.

امکانات
سه حالت محاسبه:
(الف) محاسبه‌ی افت هد و افت فشار از سرعت V یا دبی Q.
(ب) محاسبه‌ی طول لوله از روی افت هد مجاز و سرعت مشخص.
(ج) محاسبه‌ی سرعت و دبی از روی افت هد مشخص.
ورودی‌ها با انتخاب واحد: قطر D و طول L با mm/m، زبری ε با mm/m یا انتخاب از منوی جنس لوله.
منوی زبری مواد: فولاد تجاری (۰٫۰۴۵ mm)، فولاد ضدزنگ، چدن، PVC، مس، بتن صاف/زبر، سفاله، گالوانیزه، یا مقدار دستی.
خروجی‌ها: V، Re، رژیم جریان، f (Colebrook)، f (Haaland) با درصد اختلاف، افت هد hf، افت فشار ΔP (Pa و kPa).
نمودار Plotly: منحنی hf(V) با نقطه‌ی جواب فعلی نشان‌داده می‌شود.
هشدارها: ناحیه‌ی انتقالی (Re بین ۲۳۰۰ و ۴۰۰۰)، زبری نسبی بزرگ (ε/D ≥ ۰٫۰۵)، سرعت غیرمعمول (کمتر از ۰٫۰۱ یا بیشتر از ۵ m/s).
مدیریت خطا: PipeError با کد E001 تا E006 به‌صورت فارسی نمایش داده می‌شود؛ stack trace نشان داده نمی‌شود.
تب فرمول‌ها: نمایش Re، Darcy–Weisbach، Colebrook و Haaland با st.latex.
رابط فارسی و راست‌چین (RTL).

کد
معنی

E005	خصوصیات سیال (ρ یا ν) باید بزرگتر از صفر باشند.
E006	حل Colebrook همگرا نشد.

فرض‌ها
سیال تراکم‌ناپذیر و نیوتنی است.
لوله دایره‌ی مقطع، صلب و مستقیم است (بدون تغییر مسیر، پمپ، شیر یا اتصالات).
جریان یک‌بعدی، پایدار و کاملاً توسعه‌یافته است.
تنها افت در نظر گرفته‌شده، افت اصطکاکی است (افت محلی/جزئی لحاظ نمی‌شود).
شتاب گریش g = 9.81 m/s² ثابت فرض می‌شود.
مقادیر پیش‌فرض سیال برای آب در دمای ۲۰°C است: ρ = 1000 kg/m³، ν = 1e-6 m²/s.
در رژیم لامینار (Re < 2300) از رابطه‌ی تحلیلی f = 64/Re استفاده می‌شود.
در رژیم آشفته (Re > 4000) ضریب اصطکاک با Colebrook محاسبه می‌شود؛ مقدار Haaland صرفاً برای مقایسه نمایش داده می‌شود.
در ناحیه‌ی انتقالی (2300 ≤ Re ≤ 4000) رفتار جریان نامطمئن است؛ هسته در این ناحیه از Colebrook استفاده می‌کند و UI هشدار می‌دهد که نتیجه باید با احتیاط تفسیر شود.
زبری نسبی بسیار بزرگ (ε/D ≥ ۰٫۰۵) خارج از محدوده‌ی عملیاتی Colebrook است؛ UI هشدار می‌دهد.
در حالت (ج) (یافتن سرعت از افت هد)، حل با scipy.optimize.brentq در بازه‌ی [1e-6, 100] m/s انجام می‌شود؛ اگر جواب در این بازه نباشد، خطا می‌دهد.
تبدیل واحد‌ها (mm↔m و L/s↔m³/s) در UI انجام می‌شود؛ هیچ فرمول فیزیکی در UI محاسبه نمی‌شود.
گزارش‌های دقت (rtol) در tests/run_tests.py بر اساس مقادیر مرجع تعریف شده‌اند و نشان‌دهنده‌ی صحت هسته هستند.
